Qt 应用程序开发 · 实验二  简单文本编辑器

一、实验目的
1. 掌握混合式 UI 设计方法，能用 Qt Designer 完成界面组件属性的设置；
2. 掌握工具栏的创建与 Action 的使用，并按功能对菜单项分组；
3. 掌握多窗口应用程序设计的基本原理；
4. 掌握文本文件的读写操作。

二、已实现的基础功能
- 文件的新建、打开、保存、另存为；
- 撤销 / 重做、剪切 / 复制 / 粘贴 / 全选；
- 字体、字号、字体颜色与编辑器背景色的修改；
- 自动换行开关、行号显示开关、工具栏与状态栏显示开关；
- 窗口标题随文档修改状态自动显示 * 号。

三、扩展功能
行号栏由 QPlainTextEdit 的派生类 CodeEditor 实现，在 Designer 中通过 promote 提升控件后接入界面。
定时自动保存每隔一段时间检查一次修改状态，只有在“文档已修改且文件已保存到磁盘”时才写回原文件。
查找窗口支持连续查找、回绕查找与全部高亮；替换窗口支持单处替换与全部替换。

四、编码与异常处理
保存统一使用 UTF-8；打开时依次识别 UTF-8 BOM、UTF-16 与 GB18030，避免中文乱码。
遇到不存在的文件、只读文件、超大文件时，程序都会给出提示，并保证编辑器里的内容不丢失。
